# Release Artifact Checklist

Each release should have:

- source archive
- Windows installer EXE
- portable Windows package where supported
- Python wheel
- source distribution
- CLI package metadata
- frontend production build
- checksum file
- release notes
- version manifest
- license files
- documentation
- SBOM where practical

Every artifact must be generated from the same version/tag.

Run a clean-machine smoke test before publishing.
