# Open Questions Before Production

These must be decided and tested before final release:

1. Exact PostgreSQL Windows distribution strategy.
2. Whether PostgreSQL is bundled, installed separately, or managed through a guided installer.
3. Exact web search provider(s) and fallback strategy.
4. Browser profile/session policy.
5. Final encryption strategy for local secrets.
6. Supported Windows versions.
7. Linux support scope for v1.
8. Minimum supported RAM/storage.
9. Exact model registry source and update policy.
10. Whether background retrieval can run automatically or only after user consent.
11. Final licensing for INTLLM and bundled dependencies.
12. Final backup/export format.
