# Browser Agent Plan

Use Playwright behind a dedicated BrowserService.

## Phase 1

- open URL
- search
- read page
- extract text
- screenshots
- tab management

## Phase 2

- click
- form filling
- navigation
- structured page interaction

## Phase 3

- authenticated sessions
- advanced workflows
- stronger permission controls

## Safety

Never silently perform:

- purchases
- account deletion
- sending messages/emails
- irreversible changes
- credential submission

Require explicit user confirmation for sensitive actions.

## Browser state

Keep sessions local. Do not store passwords in ordinary database fields.
