# INTLLM Brand Assets

Production asset pack for INTLLM.

## Primary
- `png/INTLLM-logo-transparent.png` — primary transparent raster logo.
- `svg/INTLLM-logo.svg` — editable vector logo.
- `png/INTLLM-logo-white.png` / `svg/INTLLM-logo-white.svg` — dark-background version.

## Icon
- `svg/INTLLM-icon.svg` — scalable app/icon mark.
- `ico/INTLLM.ico` — Windows/favicon ICO with multiple sizes.
- `png/INTLLM-icon-1024.png` through `128.png` — app/store sizes.
- `png/INTLLM-emblem-transparent-1024.png` — transparent emblem-only mark.

## Banners
- 1600×500 general banner
- 1200×630 Open Graph / social preview
- 1280×640 GitHub social preview

## Brand colors
- Cyan: `#16C8FF`
- Blue: `#2563EB`
- Violet: `#7C2CFF`
- Dark: `#090D16`
- Wordmark dark: `#111827`
- White: `#FFFFFF`

## Recommended use
- Light UI: primary transparent logo / dark wordmark.
- Dark UI: white logo variant or icon.
- App/favicon: `INTLLM.ico` or `INTLLM-icon.svg`.
- Do not stretch, rotate, add drop shadows, or recolor the primary mark.
