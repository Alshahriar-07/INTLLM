# Memory Learning Pipeline

```text
Conversation / Retrieval Result
          |
      Candidate
          |
   Normalize + deduplicate
          |
   Evidence / provenance
          |
      Confidence
          |
    Candidate memory
          |
     Background job
          |
       Promote
          |
      L2 Secondary
          |
    update L0 index
          |
  optional L1 promotion
```

Memory should be compact. Store reusable conclusions/workflows instead of complete raw webpages whenever possible.

Keep source references so information can be revalidated.
